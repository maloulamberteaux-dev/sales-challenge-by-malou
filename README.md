# Sales Challenge by Malou — V4 Supabase

## Installation rapide

1. Dans Supabase > SQL Editor, colle le contenu de `supabase-setup.sql`, puis clique Run.
2. Dans Supabase > Project Settings > API, copie :
   - Project URL
   - anon public key
3. Dans `config.js`, remplace :
   - `COLLE_ICI_TON_PROJECT_URL`
   - `COLLE_ICI_TON_ANON_PUBLIC_KEY`
4. Upload les fichiers sur GitHub.
5. Vercel redéploie automatiquement.

## Admin

Mot de passe admin par défaut : `malou`.
Tu peux le changer dans `app.js` : `ADMIN_PASSWORD`.
